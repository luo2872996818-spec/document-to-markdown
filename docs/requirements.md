# 项目需求文档

## 1. 项目概述

制作一个本地网页工具，自动批量将电子版 PDF、Word、Excel、CSV 和 TSV 文档转换为 Markdown。

## 2. 目标用户

主要供需要整理、检索、编辑或发布大量文档的个人用户使用。

## 3. 核心功能

1. 批量选择或上传多个文档。
2. 根据文件类型自动选择转换方式。
3. 将文档内容转换为 Markdown 文件。
4. 展示每个文件的处理状态、错误信息和结果预览。
5. 打包下载全部 Markdown 文件和转换报告。

## 4. 文件格式范围

首版支持：

- PDF：只支持可提取文字的电子版 PDF。
- Word：DOCX。
- Excel：XLSX、XLSM、XLS。
- 文本表格：CSV、TSV。

首版不支持 DOC 旧版 Word 文件和扫描版 PDF OCR。

## 5. 非功能要求

- 全部转换流程在本机完成。
- 程序运行时不依赖在线 AI 服务。
- 支持中文文件名和中文内容。
- 单个文件失败不能中断整个批量任务。
- 项目依赖安装在项目自己的虚拟环境中。
- 转换结果和临时文件需要清晰分类。

## 6. 首版验收标准

- PDF、DOCX、XLSX、CSV 各至少完成一次成功转换。
- 支持多个文件连续处理。
- 页面能够显示进度、错误和结果预览。
- 结果可以打包为 ZIP 下载。
- 中文 CSV 不出现乱码。
- 扫描版 PDF 能够得到明确的不支持提示。
- 自动化测试能够通过。
