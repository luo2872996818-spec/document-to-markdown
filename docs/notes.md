## [2026-09-22] 修复 Streamlit 启动路径错误

- 浏览器中出现 `ModuleNotFoundError: No module named 'src'`。
- 原因是 Streamlit 启动时没有把项目根目录加入 Python 模块搜索路径。
- 已在 `src/main/app.py` 启动阶段根据入口文件位置自动加入项目根目录。
- 已从其他工作目录运行 AppTest，确认页面不再出现该异常。
- 13 项自动化测试继续全部通过。
